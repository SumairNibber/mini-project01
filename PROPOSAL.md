Mini Project 1 – Website for 14780 Memorial Drive
1. Client
• Client: My dad
• Owns office building at 14780 Memorial Drive
• Currently shares information via PDF / presentation
• Wants something more professional and accessible

2. Client Goals (from conversation)
• Have a clean digital presence for the building
• Make tenant directory easy to view
• Show building layout by floor
• Replace static presentation with something interactive
• Something easy to update later

3. Target Users
• Prospective tenants
• Current tenants
• Visitors looking for suite numbers
• Brokers

4. Current Situation
• 4 slides:
Landing page
Directory
Level 1
Level 2

5. Problem
• No dedicated website
• Hard to quickly find tenant info
• Directory not organized digitally
• Floor plans shown as images only

6. Proposed Solution
Build a 4-page static website:
• Home (Landing page)
• Directory page
• Level 1 page
• Level 2 page

Each page will:
• Use clean HTML structure
• Use semantic sections
• Display tenant list clearly
• Include floorplan image placeholders

7. Core Features (MVP)
• Navigation bar across all pages
• Tenant table with Suite # column
• Floor-level filtering (separate pages)
• Background hero image
• Clean typography
• Mobile-friendly layout

8. Stretch Goals (if time)
• Search bar for tenants
• Anchor links
• Hover effects
• Basic transitions
• Future ability to update tenant list easily

9. Tech Plan
• HTML for structure
• CSS for styling
• Separate CSS file
• Semantic tags
• GitHub repo (separate from oim3690 repo)
• Deploy via GitHub Pages
